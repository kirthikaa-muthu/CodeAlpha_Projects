A cybersecurity awareness presentation focused on recognizing and understanding phishing attacks.

The presentation covers:

- Phishing email indicators
- How to check suspicious links
- Legitimate vs. fake login pages
- Types of phishing
- Business Email Compromise
- Real-world phishing/impersonation case
- Security lessons and red flags
